# TripEasy – Flight Booking Website

## Run the website
    python3 -m pip install -r requirements.txt
    python3 app.py
Open http://127.0.0.1:5000

## Run the tests
    python3 -m pytest -v

## Files
- booking.py – the logic (Flight and Booking classes, search, booking, cancel, login)
- app.py – the website pages
- templates/ – the HTML pages, static/style.css – the colours
- test_tripeasy.py – the test cases TC01 to TC28
